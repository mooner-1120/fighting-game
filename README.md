# 서밋 파이터즈 (가제)

세계 정상들이 "세계 정상회의" 링 위에서 맞붙는 철권식 3D 격투 + 정치 풍자 게임입니다.
친구들끼리 PC 웹 브라우저에서 링크 하나로 접속해 노는 **비상업 풍자 패러디 프로젝트**입니다. 게임 속 대사와 연출은 실제 인물의 발언·행동과 무관합니다.

외부 유료 에셋·서비스 없이 만들었습니다. 3D 모델, 스테이지, 효과음, 배경음악은 모두 코드로 생성하고, 음성은 브라우저 내장 TTS를 씁니다.

## 직접 실행해 보기 (내 PC)

Node.js 18 이상이 필요합니다.

```bash
npm install
```

```bash
npm install --prefix server
```

```bash
npm run build
```

```bash
npm run server
```

브라우저에서 `http://localhost:8787` 을 엽니다. 같은 와이파이의 친구는 `http://내PC의IP:8787` 로 들어올 수 있습니다.

개발할 때는 터미널 두 개에서 `npm run server` 와 `npm run dev` 를 띄우고 `http://localhost:5173` 을 엽니다.

## 무료로 인터넷에 올리기 (Render)

게임 페이지, 방 관리·시그널링, 중계를 **서버 하나**가 모두 맡습니다. Render 무료 플랜에서 돌아갑니다.

1. [render.com](https://render.com) 에 가입합니다 (무료, GitHub 계정으로 가입 가능).
2. 대시보드에서 **New → Blueprint** 를 누르고 이 저장소를 고릅니다.
3. 저장소의 `render.yaml` 을 읽어 설정이 자동으로 채워지면 **Apply** 를 누릅니다.
4. 배포가 끝나면 `https://summit-fighters.onrender.com` 같은 주소가 생깁니다. 이 주소를 친구들에게 보내면 됩니다.

**무료 플랜 주의점**

- 15분 동안 아무도 접속하지 않으면 서버가 잠듭니다. 잠든 뒤 첫 접속은 깨어나는 데 30~60초 걸립니다. 한 번 깨면 그 뒤로는 바로 열립니다.
- 놀기 직전에 한 명이 먼저 주소를 열어 두면 됩니다. 항상 깨어 있게 하려면 [UptimeRobot](https://uptimerobot.com)(무료)에 `https://내주소/health` 를 5분 간격으로 등록하세요. 한 달 무료 사용 시간(750시간) 안에 들어갑니다.
- Render 무료 플랜은 UDP를 열 수 없어서 진짜 TURN 서버는 올릴 수 없습니다. 대신 P2P 연결이 6초 안에 안 되면 같은 서버의 WebSocket으로 입력을 중계합니다. 회사·학교망처럼 P2P가 막힌 곳에서도 대전할 수 있지만, P2P보다 지연이 조금 큽니다.

## 조작법

| 동작 | 1P 키보드 (기본) | 2P 키보드 (기본) | 게임패드 |
| --- | --- | --- | --- |
| 이동 | W A S D | 방향키 | 십자키 / 왼쪽 스틱 |
| LP · RP · LK · RK | U · I · J · K | 넘패드 4 · 5 · 1 · 2 (또는 `[` `]` `;` `'`) | □ · △ · × · ○ |
| 궁극기 (게이지 3칸) | U+I | 4+5 | R1 |
| 강화기 EX (게이지 1칸) | J+K | 1+2 | L1 |
| 잡기 | U+J / I+K | 4+1 / 5+2 | R2 |
| 비상 담화 (체력 25% 이하) | U+K | 4+2 | L2 |

- 가만히 있거나 뒤를 누르면 상단·중단 가드, 아래를 누르면 하단 가드입니다 (철권 방식).
- 위를 탭하면 화면 안쪽으로, 아래를 짧게 탭하면 바깥쪽으로 횡이동합니다.
- 앞으로 두 번이면 대시, 뒤로 두 번이면 백대시입니다.
- 필살기는 ↓↘→ + 버튼, ← + LP 입니다. 캐릭터별 기술은 게임 안 **기술표**에 있습니다.
- 키는 **설정 → 키 설정** 에서 바꿀 수 있고 브라우저에 저장됩니다.

## 구조

```
src/sim/       결정론적 게임 로직 (정수 연산만, 60fps 고정 스텝) — 캐릭터·기술 프레임 데이터
src/game/      롤백 넷코드, 로컬/트레이닝/온라인/관전/리플레이 진행, CPU
src/render/    Three.js 캐리커처 모델·포즈 애니메이션·스테이지·이펙트·뉴스 컷신
src/audio/     Web Audio 합성 효과음·행진곡 BGM, 브라우저 TTS 앵커
src/net/       시그널링 연결, WebRTC DataChannel + 중계 자동 전환
src/ui/        메뉴·로비·HUD·트레이닝 패널
server/        Node.js(ws) — 게임 파일 제공, 방·대진·토너먼트, 시그널링, 중계, 관전 입력 전달
tests/         결정론·기술·롤백 네트워크 시뮬레이션 테스트
```

테스트는 `npm test` 로 돌립니다. 같은 입력이면 항상 같은 결과가 나오는지(결정론), 콤보·잡기·궁극기가 의도대로 들어가는지, 패킷 손실 15%와 지연이 있는 가상 네트워크에서 두 피어가 같은 결과를 내는지 확인합니다.

## 온라인 대전이 어긋날 때

- 게임이 업데이트되면 옛 버전 페이지로는 방에 들어갈 수 없고, 자동으로 새로고침됩니다. 서로 다른 버전끼리 대전하면 화면이 어긋나기 때문입니다.
- 대전 중 두 화면이 어긋나면(0.5초마다 상태를 비교) 1P의 상태로 자동 복구합니다. 화면 아래 상태 줄에 「동기화 복구 n회」로 표시됩니다.
- 대전 중에 다른 탭이나 창으로 전환하면 브라우저가 게임을 멈춰서 상대 화면도 같이 멈춥니다. 대전 중에는 게임 탭을 앞에 두세요.

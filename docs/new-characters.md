# 새 캐릭터 4인 설계 (게임 코딩 담당 · 모델 담당 공통 약속)

PRD의 레이디 펫터스·박길남·알자르·마르셈 듀랑을 실존 인물 풍자 캐릭터로 바꿔 만든다.
기존 4인(이재명·푸틴·트럼프·김정은)과 같은 구조를 쓴다: 시뮬레이션은 `src/sim/chars/<id>.ts`, 겉모습은 `src/render/`.

## 공통 규칙

- **결정론:** 시뮬레이션은 정수 연산만, `rand(s)` 외의 난수·시간 금지 (롤백 넷코드).
- **명령 표기:** `qcf1` = ↓↘→+LP, `qcf2` = ↓↘→+RP, `41` = ←+LP, `ex` = LK+RK(게이지 1칸), `ult` = LP+RP(게이지 3칸, 라운드당 1회). 기본기(`baseMoves()`)는 그대로 둔다.
- **필요하면 새 명령 추가 가능:** 예) `42` = ←+RP, `qcb1` = ↓↙←+LP. `src/sim/moves.ts`의 명령 해석에 없으면 게임 코딩 담당이 추가한다.
- **궁극기:** 발생 15F 이상, 가드 가능, 가드 시 큰 후딜레이 (`ultMove()` 기본값을 따른다). 효과는 `hooks.ultApply`에서.
- **애니메이션 이름(`anim`):** 아래 표의 이름을 그대로 쓴다. 모델 담당이 `src/render/poses.ts`에 같은 이름(+ `_w` 준비 자세)으로 포즈를 만든다.
- **투사체 종류(`kind`):** 아래 표의 이름을 그대로 쓴다. 모델 담당이 `src/render/view.ts`에서 모양을 만든다.
- **고유 자원:** `f.res[0]`(필요하면 `res[1]`). HUD 표시는 게임 코딩 담당이 `src/ui/hud.ts`에 추가한다.
- **화면에 보여야 하는 상태**(예: 잠적 중 반투명)는 `Fighter`/`Buffs`에 필드를 추가하고 이 문서 「렌더 연결」 칸에 적는다.

## 파일 담당

| 담당 | 고치는 파일 |
| --- | --- |
| 게임 코딩 | `src/sim/**` (단, 각 캐릭터 파일의 `look`은 손대지 않음), `src/game/ai.ts`, `src/ui/hud.ts`, `src/ui/menus.ts`, `server/`, `tests/`, 이 문서의 「렌더 연결」 칸 |
| 모델 | `src/render/**`, `src/sim/chardef.ts`의 `CharLook` 타입, 각 캐릭터 파일의 `look: { ... }` 블록 |

## 1. 마거릿 대처 — `thatcher` (영국, 철의 여인 / 우산 리치형)

| 명령 | 기술 | anim | 투사체 | 내용 |
| --- | --- | --- | --- | --- |
| ↓↘→+LP | 장우산 찌르기 | `umbrella` | — | 리치 긴 중단 찌르기 (기본기보다 30~40% 멀리) |
| ↓↘→+RP | 이층버스 낙하 | `summonBus` | `bus` | 상대 머리 위에서 빨간 이층버스가 떨어진다 (중단, 다운) |
| ←+LP | 의회 질의 | `question` | — | 짧은 거리 질문 공격. 맞으면 상대 짧은 경직(스턴) |
| LK+RK | 장우산 회전 EX | `umbrella` | — | 아머 + 다단 찌르기 |
| 고유 | 티타임 | `tea` | — | 10초마다 「티타임」 알림. 그 뒤 3초 안에 ↓+LP+RP(또는 지정 명령)로 차를 마시면 체력 회복. 마시는 동안은 무방비 |
| 궁극기 | 해협 봉쇄 | `ult` | — | 무대에 물이 차오르고 군함이 포격. 피해 + 상대 5초 이동 둔화 |

렌더: 금발 볼륨 단발(헬멧형), 진주 목걸이, 파란 스커트 정장, 핸드백(선택), 손에 장우산·찻잔. 궁극기 컷신: 물 차오름, 회색 군함, 포탄.

| 명령 | 기술 | anim | 투사체 | 내용 |

| ↓↘→+RP | 연산 방벽 설치 | `firewall` | `firewall` | 앞쪽에 붉은 데이터 방벽 설치. 상대 투사체·돌진을 막는다 (트럼프 장벽과 비슷) |

렌더: 단정한 검은 올백 머리, 둥근 얼굴, 짙은 정장·빨간 넥타이, 국기 배지. 드론(쿼드콥터), 붉은 격자 방벽.

## 3. 무함마드 빈 살만 — `mbs` (사우디아라비아, 오일머니 왕세자 / 스피드형)

## 렌더 연결 (게임 코딩 담당이 채운다)

시뮬레이션에서 새로 만든 상태·이벤트 중 화면에 보여야 하는 것을 적는다.

| 캐릭터 | 필드/이벤트 | 뜻 |
| --- | --- | --- |
| 공통 | `s.cine.v` | 궁극기 연출 진행 값. 컷신 중 매 프레임 `hooks.ultTick`이 갱신 (뜻은 캐릭터별 아래 칸). 기존 4인은 항상 0 |
| 공통 | 투사체 `p.y`, `p.vy` | 이제 `vy`가 있는 투사체는 매 프레임 `y`가 변한다 (버스 낙하, 매 하강). 렌더는 `p.y`를 그대로 쓰면 된다 |
| 공통 | 이벤트 `{ k: 'justGuard', who }` | 저스트 가드 성공 (현재 마크롱만). 반짝임·효과음용 |
| 공통 | 이벤트 `{ k: 'teaTime', who }` | 대처 티타임 창이 열림 (찻잔 아이콘·종소리용) |
| 대처 | `f.res[1] > 0` | 티타임 창 열림 (남은 프레임). 머리 위 ☕ 표시 등 |
| 대처 | `f.res[0]` | 다음 티타임까지 남은 프레임 (0~600) |
| 대처 | `f.st === 'atk' && f.move === 'tea'` (anim `tea`, 56F) | 차 마시는 중. 38F에 회복(`heal` 이벤트) |
| 대처 | 투사체 `kind: 'bus'` | 상대가 있던 자리 `(tx, tz)`로 `y` 3400 → 0 까지 34F 동안 떨어짐. 반지름 420. 착지 시 `boom` 이벤트 |
| 대처 | `s.cine.v` | 물 높이 mm (0 → 1200, 약 1.4초 동안 차오른 뒤 유지) |
| 대처 | `f.buffs.slow` (상대) | 궁극기 뒤 상대 이동 둔화 남은 프레임 (푸틴 궁극기와 같은 필드) |
| 시진핑 | `f.buffs.hidden > 0` | 장기 오프라인 잠적 중 → 반투명. 끝날 때 상대 뒤로 순간이동 (`x, z`가 한 번에 바뀜) |
| 시진핑 | `f.buffs.briefing > 0` | 감시망 가동 중 (이재명 긴급 브리핑과 같은 필드 → 상대 기술 예고 말풍선이 이미 뜬다) |
| 시진핑 | `f.res[0]` | 감시망 게이지 0~100 |
| 시진핑 | 투사체 `kind: 'drone'` | 드론. `y` 1550, 일렬로 3대(EX 5대)가 순서대로 날아감. 방향은 `(vx, vz)` |
| 시진핑 | 투사체 `kind: 'firewall'` | 연산 방벽. 위치 `(x, z)`, 바라보는 방향 `(tx, tz)`(×1000 단위벡터, 트럼프 `barrier`와 같은 규칙), 반지름 480, 300F 유지, 한 번에 하나 |
| 시진핑 | `s.cine.v` | 붉은 벽 높이 mm (0 → 3000, 75F 동안 솟음) |
| 시진핑 | `f.buffs.cage`, `cageX`, `cageZ` (상대) | 궁극기 뒤 가두기 남은 프레임과 중심. 반지름은 `CAGE_R`(1600mm, `src/sim/types.ts`). 이 원 둘레에 붉은 벽을 그리면 된다 |
| 빈 살만 | `f.res[0]` | 유가 0~100 (HUD는 `$40 + res[0]`로 표시) |
| 빈 살만 | `f.res[2]` | 1 = 유가 오르는 중, 0 = 내리는 중 |
| 빈 살만 | `f.buffs.hidden > 0` | 모래폭풍 대시 중 (몸 충돌 없음, 모래 효과). 위치는 매 프레임 직접 이동 |
| 빈 살만 | 투사체 `kind: 'falcon'` | 매. `y` 2150에서 프레임당 30씩 내려와 1300에서 수평 비행 |
| 빈 살만 | `s.cine.v` | 원유 기둥 높이 mm (컷신 90F까지 0, 그 뒤 프레임당 80씩, 최대 6000) |
| 빈 살만 | 궁극기 직후 상대 `st === 'air'`, `vy` 120 | 상대가 아주 높이 뜬다 (추가타용). 별도 렌더 필요 없음 |
| 마크롱 | `f.res[0]` | 우아함 0~100 |
| 마크롱 | 이벤트 `justGuard` | 저스트 가드 성공 |
| 마크롱 | 기술 `qcf1` → `qcf1b` → `qcf1c` | 레이피어 1·2·3타. 모두 anim `rapier` (필요하면 2·3타 포즈를 따로 만들어도 됨: `f.move`로 구분) |
| 마크롱 | 투사체 `kind: 'baguette'` | 바게트. `y` 1200, 직선 비행 (회전은 렌더에서) |
| 마크롱 | `f.move === '41'` (anim `toast`, 72F) | 와인 건배. 42F에 회복 |
| 마크롱 | `s.cine.v` | 총파업 중 찌른 횟수 (컷신 90F부터 10F마다 +1, 최대 12). 값이 바뀔 때마다 찌르기 동작 |

명령 추가: 대처 티타임은 **↓ + LP+RP** (티타임 창이 열렸을 때만. 창 밖에서는 기존대로 궁극기/일반기).
